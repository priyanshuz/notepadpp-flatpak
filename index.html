Notepad++ Flatpak Repository

Unofficial Flatpak package for Notepad++ running on Wine.

Use the install ref directly:

com.notepadplusplus.NotepadPlusPlus.flatpakref

  • Flatpak remote files: repo/
  • Install command: flatpak install --user https://${GITHUB_REPOSITORY_OWNER}.github.io/${GITHUB_REPOSITORY#*/}/com.notepadplusplus.NotepadPlusPlus.flatpakref
